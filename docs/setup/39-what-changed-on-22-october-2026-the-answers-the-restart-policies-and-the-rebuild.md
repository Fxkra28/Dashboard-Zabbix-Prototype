## A rebuild script and a tag (IN-01)

`deploy/rebuild.sh` makes the steps of §23: a gate (the parity check and `npm run verify`), the rollback tags, the build of hosted and then local-model with the commit and the time, the wait for the containers to be healthy, and what an anonymous caller sees. It refuses a tree whose `server/`, `web/` (their tests apart) or compose file differ from the commit, because a build named by a commit has to be what that commit holds. On a clean tree it makes the annotated tag `live-<date>` and never pushes it. `--dry-run` prints what it would do. It has 12 tests in `rebuild-script.test.ts`, run as a dry run in temporary trees with a stand-in for docker, and eleven deliberate breakages of the script were each caught. The first mutation run found a real fault: with a docker that says every tag exists the search for a free rollback tag never ended, so the search now stops at 50 and the test kills a script that runs for twenty seconds.

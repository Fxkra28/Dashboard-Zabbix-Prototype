# The A to Z index of names

| Who it is for | Reading time | Read first | Read next |
|---|---|---|---|
| Developers | about 1 min | [Tools files, one card each](files-tools.md) | [The tests map](tests-map.md) |

Every name that a code file exports, in alphabetical order, with its kind and the file and line where it is declared. It covers the server, the web app and the tools. Use it when you know a name from a log line, a test failure or a conversation, and want the file. The page is written by `npm run handover:build` from the code, so a new export appears here by itself and a removed one disappears. It lists declared names only: a name that a file re-exports from another is listed at the place it is declared.

The kinds are the ones the cards use. A function and a component are told apart by the name and the file type. A constant is any exported value that is not a function. A type is an interface, a type alias, a class or an enum.
